# Stumps Ahead roadmap

What has shipped, what is being built now, and the ideas still to choose from. Karen (PM) updates this file in every release PR. Ideas come from the Researcher's list (`/mnt/project-files/researcher/what-to-build-next-v1.3.1.md`), and Talati picks what goes next. Details for each release are in `SPEC.md` and `CHANGELOG.md`.

## Shipped

- [x] **v1.0.0**: base game with 7 nations, fictional squads, toss, two innings and result. Phase 2 graphics. Phase 3 batting upgrade (move across the crease, visible lofts, correct left/right-hand stances).
- [x] **v1.1.0**: drag the landing ring when bowling. Bowling variations. Two real home grounds per nation. Red/white/pink ball, with pink = night match. Version shown in the game.
- [x] **v1.2.0**: its own Venue screen between Setup and Toss. Fixed the swing path so yorkers stay on the pitch.
- [x] **v1.3.0**: wides only when the ball is actually wide. Over/around the wicket. Swipe-to-hit and the aim arrow removed (buttons only).
- [x] **v1.3.1**: arrival marker removed from the play view.
